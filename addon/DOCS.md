# Personal Cycling Agent

Cycling telemetry analytics with Garmin Connect sync and AI-powered insights.

## Configuration

- **Garmin Connect email/password**: Required for automatic activity sync.
- **FTP (watts)**: Your Functional Threshold Power for zone calculations.
- **Max HR**: Your maximum heart rate for HR zone calculations (0 = auto).
- **OpenAI / Anthropic API keys**: Optional, for AI-powered cycling insights.

## Features

- Automatic Garmin Connect activity and stream data sync
- Power, heart rate, and cadence analytics
- W' capacity and training load calculations
- Route heatmap visualization
- AI-powered cycling insights and recommendations

## Data Storage

All data is stored in the add-on's data directory and persists across updates.
